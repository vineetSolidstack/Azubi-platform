# Decisions

Date, decision, reason. Newest at the bottom.

| Date | Decision | Reason |
|---|---|---|
| 2026-11-22 | Repo started from scratch. | The repo contained only a README; no earlier SPS-Trainer code was present to reuse. |
| 2026-11-22 | No Supabase, accounts or paywall yet. Progress is stored in localStorage behind the `ProgressStore` interface in `src/lib/progress.ts`. | Owner wants to try the app first and connect Supabase later. |
| 2026-11-22 | One execution engine: ladder (KOP) is translated to SCL text, SCL is parsed and run by the scan-cycle runtime. | One place for instruction behaviour and tests; the learner can see their ladder as SCL. |
| 2026-11-22 | Fixed cycle time of 10 ms; timers use PLC time, not wall-clock time. | Deterministic grading; same result in browser, tests and grader. |
| 2026-11-22 | Grading is behavioural only: input changes over time, expected values at given moments, plus "never" conditions. | Any correct program must pass; no comparison with a model solution. |
| 2026-11-22 | Test expectations sit at least 100 ms away from a switching moment. | Leaves room for correct programs that need a few extra cycles (step chains, edge flags). |
| 2026-11-22 | Writing to an input variable is a compile error. | Helps beginners; open point: real controllers allow it. Revisit if a correct program is ever rejected. |
| 2026-11-22 | `F_TRIG` gives no pulse in the first scan. | Deviates from the letter of IEC 61131-3 to avoid a confusing start-up pulse. |
| 2026-11-22 | Ladder editor model: a rung is a series of groups, a group is a set of parallel branches. Counters and comparisons are SCL only for now. | Covers the first tasks with a small editor; FUP view and GRAFCET display are still open. |
| 2026-11-22 | All content is `draft`. The footer and each item say so. | Content rules: nothing is reviewed by a qualified person yet. |
| 2026-11-22 | Every task has an `explanation` (why the reference solution is built that way). The complete solution and the explanation can be opened at any time, not only after failed attempts; the solution can be loaded into the editor. | Owner's request: try several times, then reveal the full answer and the reasoning, and experiment from there. |
| 2026-11-22 | New content type "Übungen" (`content/exercises/`, `src/exercises/`): multi-step calculation exercises, each step checked on its own, with formula, worked calculation, a "why" per step and a takeaway, in German and English. A test checks that every worked calculation ends in the stored answer. | Owner wants exercises with full solutions and explanations for all topics, not only quiz questions. This widens the first version beyond M05 to M08; started with M01 (Lernfeld 1). |
| 2026-11-22 | Lernfeld titles checked against the KMK Rahmenlehrpläne (version of 23.02.2018) for EAT, Mechatroniker and Industriemechaniker. EAT titles stay as they were. | A list from a school website showed other titles; those belong to the Handwerk trade "Elektroniker/-in" (2020), not to Elektroniker für Automatisierungstechnik. |
| 2026-11-22 | Owner decision: build the complete product for all modules and all three trades (Übungen for every module, own simulators for Industriemechaniker), not only the earlier first-version scope. Work proceeds in batches, one PR each. | Owner: "I need all, I am creating a complete module." The earlier scope limit (M05 to M08, 30 PLC tasks) no longer applies. |
| 2026-11-22 | First Industriemechaniker simulator is the caliper reading trainer (`src/engine/measure/`), 1/20 vernier (20 divisions over 39 mm). Order after it: pneumatic circuit builder, then CNC path simulator. | Smallest simulator, useful from year 1; pneumatics also serves Mechatroniker. |
| 2026-11-22 | Every module gets three layers: a theory lesson (`content/theory/`), Übungen from easy to very hard (difficulty 1 to 5 with labels), and where it fits a simulator. Theory pages link to the matching practice. | Owner: a theory session and exercises in all modules, with difficulty up to exam level. |
| 2026-11-22 | Technical drawing trainer for Industriemechaniker: the learner draws the visible edges of front view, side view from the left and top view (projection method 1) for block-shaped solids defined as height maps. | Owner wants technical drawing and view reading rather than only the caliper. Hidden edges, dimensions, sections and round features are later steps. |
| 2026-11-22 | Drawing trainer: hidden edges (dashed lines) are graded only for workpieces marked `hidden: true`; older workpieces stay visible-edges only. | Keeps the easy workpieces easy and adds an exam-relevant step for the hard ones. |
| 2026-11-22 | Inside a module the Übungen are listed from easy to very hard. Level 5 ("sehr schwer") combines several ideas in one task. | Owner: exercises from easy to very hard to prepare for exams. |
| 2026-11-22 | Safety lessons (M03, M04) only state limit values that were found in public DGUV and DKE documents on 2026-11-22; the sources are named on the lesson page. Body-current thresholds are worded as ranges because sources differ. Still requires review by an Elektrofachkraft before publication. | Content rule: flag limit values instead of guessing; wrong safety content is worse than missing content. |
